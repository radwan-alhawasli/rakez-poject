## 📖 نظرة عامة

تم تكامل جميع APIs الخاصة بإدارة الفرق من مجموعة Postman في تبويبة **"إدارة الفرق"** ضمن قسم **الموارد البشرية (HR)**. التكامل يشمل:

✅ **فلترة وعرض الفرق** (Teams → filter & Show)

## 🔗 APIs المستخدمة

### 1. جلب وفلترة الفرق
```http
GET /teams/index?search={name}
```
**الاستخدام:**
- عرض جميع الفرق في الشبكة
- البحث عن فريق محدد بالاسم
- حفظ `id` و `name` لكل فريق

---

### 2. جلب عقود الفريق
```http
GET /hr/teams/contracts/:id
```
**الاستخدام:**
- عرض عدد المشاريع في بطاقة الفريق
- عرض تفاصيل المشاريع في modal

---

### 3. جلب مواقع عقود الفريق
```http
GET /hr/teams/contracts/locations/:id
```
**الاستخدام:**
- عرض ملخص المواقع في بطاقة الفريق
- عرض موقع كل مشروع (مدينة - حي) في modal

---

### 4. متوسط مبيعات الفريق
```http
GET /hr/teams/sales-average/:id
```
**الاستخدام:**
- عرض متوسط مبيع الفريق في البطاقة
- حساب تقدم الفريق نحو أهدافه

---

## 💻 مثال كود بسيط

### جلب الفرق مع البحث
```javascript
import hrService from '@/services/hrService'

// جلب جميع الفرق
const teams = await hrService.getTeams()

// البحث عن فريق محدد
const searchResults = await hrService.getTeams({ search: 'مبيعات' })
```

### جلب مشاريع فريق
```javascript
// جلب عقود الفريق
const contracts = await hrService.getTeamContracts(teamId)

// جلب مواقع العقود
const locations = await hrService.getTeamContractLocations(teamId)

// جلب متوسط المبيعات
const salesAverage = await hrService.getTeamSalesAverage(teamId)
```

## 🔧 استكشاف الأخطاء

### المشكلة: لا تظهر الفرق
**الحلول:**
1. افتح Console (F12) وتحقق من الأخطاء
2. تحقق من Network tab → /teams/index
3. تأكد من صلاحيات المستخدم (type = 8/9/'hr')

### المشكلة: عدد المشاريع دائماً 0
**الحلول:**
1. تحقق من Network tab → /hr/teams/contracts/:id
2. افحص استجابة API (هل data موجودة؟)
3. تحقق من Console للأخطاء

### المشكلة: لا تظهر المواقع
**الحلول:**
1. تحقق من Network tab → /hr/teams/contracts/locations/:id
2. تأكد من وجود city و district في البيانات

**للمزيد:** راجع `TESTING_GUIDE_HR_TEAMS.md` قسم "المشاكل المحتملة"
